# School Vault — Wiki Rules

This vault stores study material: courses, lectures, textbooks.

## Organization

Organize by **course, then topic**:

```
wiki/
  index.md
  <course-name>/
    <topic>.md
```

Example: `wiki/microeconomics/supply-and-demand.md`.

## Topic file structure

Each topic file must contain:

1. **Plain-language summary** — explain it like I'm hearing it for the first time.
2. **Key terms and formulas** — definitions and formulas from the source material.
3. **Likely exam questions** — questions this topic could produce on a test.
4. **Related topics** — `[[wikilinks]]` to other topic files.
5. `## Sources` — raw filenames the content came from.

## Quiz mode

When I say "quiz me on X" (a topic, course, or the whole vault):

1. Pull questions from the wiki content for X: use the "likely exam questions" plus new questions built from key terms and formulas.
2. Ask **one question at a time**. Wait for my answer.
3. Grade my answer: right or wrong, plus the correct answer from the wiki with a short explanation.
4. Keep going until I stop, then give a score summary and which topics to review.
