# Question Hooks

Hooks that open with a direct question posing a challenge, usually one the creator is about to attempt on camera.

## Examples

### "Is it possible to become disgustingly educated in 60 days?" (TikTok, @alexxubuilds)

> **Spoken:** "Is it possible to become disgustingly educated in 60 days?"
>
> **On-screen text:** "Is it possible to become DISGUSTINGLY EDUCATED in 60 DAYS"

**Why it works:**
- Framing self-improvement as a stark, high-stakes question ("disgustingly educated") triggers curiosity about the answer.
- Immediately followed by authority proof (incoming Stanford student), so the challenge reads as credible instead of empty talk.
- Sets up a series (30 days relearning ML + 30 days engineering) — the question isn't answered in this video, only by following.

### "Can you become cracked at machine learning in 30 days?" (TikTok, @alexxubuilds)

> **Spoken:** "Can you become cracked at machine learning in 30 days?"
>
> **On-screen text:** "Can you become CRACKED at machine learning in 30 days?"

**Why it works:**
- Same challenge-question shape as the 60-day video, scoped down to one specific, testable claim.
- "Well, I'm trying to find out" right after the hook turns the viewer into a witness to a real experiment, not a lecture.
- "This is Day 1" anchors the question to a concrete, checkable timeline immediately.

### "Is it possible to learn everything in this famous 33 hour course by Andrew Ng in one afternoon?" (Instagram, @alexxubytes)

> **Spoken:** "Is it possible to learn everything in this famous 33 hour course by Andrew Ng in one afternoon?"
>
> **On-screen text:** same line, paired with a Coursera course screenshot.

**Why it works:**
- Same challenge-question shape as the other two, but the stakes are a named, specific external benchmark (a famous 33-hour course) instead of a vague skill claim, which makes the challenge easier to picture and judge.
- This is "Day 2" of the same "cracked at machine learning in 30 days" series as the example above — note the on-screen handle here reads **@alexxubytes**, not @alexxubuilds as in the Day 1 source. Flagging the mismatch rather than assuming it's the same account.
