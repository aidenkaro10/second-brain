# FULL TRANSCRIPT

*(Note: Due to the 50-minute video length, this transcript follows the section-by-section breakdown format with tight summaries and key verbatim quotes).*

### 0:00 - 0:34: Introduction
Kedasha welcomes viewers and introduces the beginner guide to installing, configuring, and understanding Git and version control.
> *"Today, I'm going to teach you everything you need to know to get started with Git. If you're an absolute beginner, this video will help you feel more confident installing, configuring, and understanding Git and version control."*

### 0:34 - 2:58: What is Git?
Explanation of version control systems and how Git tracks file changes over time without cluttering directories with duplicate files.
> *"Git is the most widely used version control system in the world. Version control is a system that tracks changes to files over a period of time."*

### 2:58 - 5:02: Core Git Concepts
High-level overview of core Git terminology including the working directory, staging area, local repository, remote repository, branches, pull requests, and merging.
> *"The working directory is where you make changes to your files... The staging area, or index, is where you prepare your changes before committing them... Your local repository is your project's history stored on your computer."*

### 5:02 - 8:45: Installing Git (macOS & Windows)
Demonstration of downloading and installing Git using Homebrew on Mac and standard installer prompts on Windows.
> *"To use Git, you need to download it on your machine... Open up your terminal and paste the command `brew install git`."*

### 8:45 - 14:17: Basic Git Commands
Demo of essential command-line interface commands: `git config`, `git init`, `git status`, `git add`, and `git commit`.
> *"The `git config` command allows you to set Git configuration values that can help you create a customized Git workflow... `git init` allows Git to start tracking our changes."*

### 14:17 - 18:48: Branching & Remote Repositories
Introduction to cloning remote repositories, creating local branches, modifying code in VS Code, and switching between branches.
> *"A branch in a Git repository is like creating a copy of a document so you don't mess up the original... `git checkout -b <branch name>` allows us to create a new branch and switch to the branch at the same time."*

### 18:48 - 22:56: Pushing, Pulling & GitHub Flow
Demonstrating how to push local commits upstream, create pull requests, pull down remote changes, and inspect project history with `git show`.
> *"The command `git push` tells Git: thanks for tracking these file changes, now I want to upload these changes into the main project file... `git pull` will fetch all the changes that were made and merge them into our local branch."*

### 22:56 - 28:01: Creating a Repository, Licenses & .gitignore
Christina Warren joins to demonstrate creating a new repository on GitHub, choosing licenses, and using `.gitignore` files.
> *"A repository, or a repo, is a space where project files live, allowing for version control and collaboration... A license basically tells others what they can and can't do with your source code."*

### 28:01 - 31:52: GitHub Features & Settings
Overview of GitHub project management tools (Issues, Projects, Wikis, Actions) and repository management settings.
> *"GitHub repositories come packed with features to enhance collaboration and project management... Collaborators settings allow you to manage who has access."*

### 31:52 - 37:14: Adding Code (CLI vs. GitHub Desktop)
Demonstration of cloning, committing, and pushing code using both command line tools and the GitHub Desktop GUI interface.
> *"GitHub Desktop gives us an option to go ahead and commit changes to this branch... and push our code to the remote repo."*

### 37:14 - 40:44: Uploading Files to GitHub
Instructions on uploading existing files directly via the GitHub UI and linking an existing local directory via terminal.
> *"Command line instructions let you push an existing repository by running `git remote add origin` and `git push -u origin main`."*

### 40:44 - 44:09: Creating Pull Requests & Best Practices
Detailed walkthrough for opening PRs, along with 3 best practices for PRs: keep them small, review your own work first, and provide clear context.
> *"1. Write small pull requests. 2. Review your own pull requests first. 3. Provide context and guidance."*

### 44:09 - 47:13: Merging & Resolving Conflicts
Reviewing PRs, merging changes into `main`, and step-by-step CLI conflict resolution using merge markers.
> *"A merge conflict occurs when changes are made to the same part of the same file on two different branches. All merge conflicts must be resolved before you can merge a pull request."*

### 47:13 - 50:47: Security & Profile Customization
Configuring Two-Factor Authentication (2FA) with an authenticator app and designing a personalized GitHub Profile README.
> *"The best way to improve the security of your personal account is to configure two-factor authentication or 2FA... The GitHub profile README acts as an about-me page to introduce yourself."*
