# CORE LESSON

You can build custom Claude Code agents that learn high-level skills directly from YouTube tutorials in three steps. By pairing a GitHub transcript plugin with Google's Gemini API via an MCP server, your AI agent gains two layers of understanding—raw text transcripts from the video plus Gemini’s native analysis of video frames and audio. This enables Claude Code to replicate specialized skills like video editing, cold email writing, or outreach marketing based on top YouTube content.

# TACTICS AND NUMBERS

- **Step 1: Install Transcript Capability**: Install the `watch-claude-video` skill from GitHub (`bradautomates/claude-video`) into Claude Code so it can extract transcripts and time-stamped text explanations.
- **Step 2: Connect Gemini API via MCP**: Get a free Gemini API key from Google AI Studio and connect it to Claude Code using the YouTube Analysis MCP server (`youtube-studio-mcp`). Gemini processes the native video frames and audio while Claude processes the text transcript.
- **Step 3: Build Multi-Skill Agents**: Feed 10 high-quality YouTube tutorials on a specific subject (e.g., video editing, cold emails, ad strategy) into Claude Code to create a dedicated agent that executes using the best techniques from those videos.
- **Free Tier API Key**: Google AI Studio provides free Gemini API access capable of handling YouTube links directly.
