# CORE LESSON

AI-assisted coding ("vibe coding") spans three distinct skill levels. Level 1 relies on basic prompts that produce generic "AI slop" without planning or structural guidance. Level 2 uses structured UI design bases (like shadcn), basic AI skills, and plan-before-execute modes. Level 3 maximizes code quality by pairing advanced AI agent skills, technology-specific AI skill extensions (e.g., Supabase, Convex), and existing proven libraries.

# TACTICS AND NUMBERS

- **Level 1 Vibe Coder:**
  - Creates "AI slop" landing pages with generic AI tropes (gradient text, scroll animations, side-tap borders).
  - Does not use `Agent.md` markdown files or custom AI skills to guide the model.
  - Skips plan mode when asking the AI to implement new features.

- **Level 2 Vibe Coder:**
  - Establishes a UI base using design systems like `shadcn` so AI does not rebuild UI logic from scratch.
  - Adds basic AI skills via CLI commands (e.g., `npx skills add ... --skill frontend-design` or `--skill shadcn`).
  - Uses Plan Mode for complex features: 1) Initiate plan mode, 2) Read/review plan, 3) Approve plan before execution.

- **Level 3 Vibe Coder:**
  - Integrates advanced AI skills (e.g., Matt Pocock skills library, Anthropic Claude Code security review plugin).
  - Installs official tech-stack skills for backend technologies used in the project (e.g., Supabase agent skills, Convex agent skills).
  - Searches for and integrates established, proven third-party libraries instead of having the AI re-invent logic from scratch.

# CONTEXT

The creator demonstrates software development workflow levels using modern AI coding agents (Claude Code, Cursor skills, and CLI tools) to illustrate best practices in AI-assisted engineering.

# HOW TO APPLY

- Establish a solid design framework base (e.g., `shadcn`) before generating UI elements so the AI adheres to strict styling patterns.
- Enable plan mode prior to executing complex code changes to review and approve architectural steps before execution.
- Install official stack-specific AI agent skills (e.g., Supabase, Convex) and leverage existing code libraries rather than asking AI to write custom implementations from scratch.
